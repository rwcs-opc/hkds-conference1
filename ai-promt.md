Create a modern, premium, highly polished, responsive website for an organization named:

**Institute for Sustainable Technology and Societal Development (ISTSD)**

The website should present ISTSD as a forward-looking research, innovation, technology, and societal-development institute working at the intersection of **sustainable technology, digital innovation, research, environment, education, entrepreneurship, and community development**.

## 1. Technology Requirements

Build the website using:

* HTML5
* CSS3
* Vanilla JavaScript
* Responsive design
* CSS animations and transitions
* Modern semantic HTML
* Google Fonts
* Font Awesome or another suitable icon library
* No backend required
* Organize the project cleanly into:

  * `index.html`
  * `css/style.css`
  * `js/script.js`
  * `images/`

The website must work perfectly on:

* Desktop
* Laptop
* Tablet
* Mobile

Do not make it look like a generic Bootstrap template. Create a **custom premium institutional design**.
